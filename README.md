# Practice Project: Cairo Housing Data Story

An end-to-end exploratory data analysis (EDA) project investigating the Cairo residential real estate market, covering district valuations, feature impacts, and strategic market insights.

## 📂 Repository Structure
- **data/**: Contains raw(`cairo_rentals.csv`, `district_info.csv`).
- **docs/**: Project documentation, data story reports, and research questions.
- **notebooks/**: Jupyter Notebook containing the exploratory data analysis workflow (`exploratory_analysis.ipynb`).
- **outputs/**: Generated charts (`chart1.png` to `chart4.png`) and interactive visualizations (`interactive_map.html`).

## 📊 Core Analytical Questions
1. **District Valuation:** Which Cairo districts command the highest median rent and price per square meter?
2. **Feature Importance:** How do square meterage, number of bedrooms, and furnishing status correlate with rental prices?
3. **Market Momentum:** Which neighborhoods experience the most aggressive rent increases?
4. **Data Integrity:** Handling outliers and phantom listings to establish accurate market baselines.
